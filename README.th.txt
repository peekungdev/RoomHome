RoomHome 1.2.0 - หน้าจอหลักสำหรับพีซีห้องประชุม บน Windows 11 (x64, x86, ARM64)
=============================================================================
(English: README.txt)

RoomHome แสดงนาฬิกา ปฏิทิน และแถบแอปสำหรับการประชุมแบบเต็มจอ เพื่อให้พีซีในห้องประชุม
แสดงสิ่งที่มีประโยชน์อยู่เสมอ แอปประชุมจะเปิดทับด้านบน และเมื่อปิดแอปก็จะกลับมาที่ RoomHome
ใช้งานได้ทั้งหน้าจอสัมผัส เมาส์ คีย์บอร์ด และรีโมตพรีเซนเทชัน (ปุ่มลูกศร + Enter)

ภาษา: ภาษาไทยหรือภาษาอังกฤษ เปลี่ยนได้ที่ การตั้งค่า > ภาษา ตัวเลือก "อัตโนมัติ" จะใช้ภาษาที่เลือก
ตอนติดตั้ง หรือถ้าไม่ได้เลือกไว้ จะใช้ภาษาที่แสดงของ Windows ในโหมดภาษาไทย วันที่จะใช้ชื่อวันและเดือน
ภาษาไทย และปีพุทธศักราช (2569)

บนหน้าจอ
--------
มุมซ้ายบน     ชื่อห้องและคำบรรยาย แตะเพื่อเปลี่ยนชื่อ (ถ้าเว้นคำบรรยายว่างไว้ จะแสดงที่อยู่ IP แทน)
แถบด้านบน    Wi-Fi (แตะ: เลือกเครือข่าย ใส่รหัสผ่าน เชื่อมต่อ / ลืมเครือข่าย เปิด/ปิด Wi-Fi)
              LAN (แตะ: ความเร็ว IP เกตเวย์ DNS และ MAC ของทั้งแบบใช้สายและ Wi-Fi) จุดสีบอกสถานะ
              อินเทอร์เน็ต: เขียว = ออนไลน์ เหลืองอำพัน = มีเครือข่ายแต่ไม่มีอินเทอร์เน็ต แดง = ออฟไลน์
              ระดับเสียง: แตะรูปลำโพงเพื่อปิดเสียง กด - / + (กดค้างเพื่อปรับต่อเนื่อง) หรือลากแถบ
              ดวงอาทิตย์/ดวงจันทร์: สลับธีมและภาพพื้นหลังโหมดสว่าง/มืด
              เฟือง: การตั้งค่า   ปุ่มพลังงาน: ปิดเครื่อง / รีสตาร์ท (กดค้าง 1.5 วินาที)
ตรงกลาง       วิดเจ็ตได้สูงสุด 4 ชิ้น (ดูด้านล่าง) ค่าเริ่มต้น: นาฬิกาเข็ม นาฬิกาดิจิทัลพร้อมวินาที
              และปฏิทินรายเดือน (กด < > เพื่อเลื่อนเดือน แล้วจะกลับมาเดือนปัจจุบันเองหลัง 1 นาที)
แถบแอป       แอปได้สูงสุด 6 แอป แตะเพื่อเปิด

การแก้ไขหน้าจอหลัก: กดค้างที่วิดเจ็ตหรือแอป (หรือคลิกขวา แตะรูปดินสอข้างแถบแอป หรือไปที่
การตั้งค่า > แก้ไขหน้าจอหลัก) ทุกอย่างจะสั่นเล็กน้อย จากนั้น
  - ลากวิดเจ็ตหรือแอปเพื่อย้ายตำแหน่ง
  - แตะเพื่อแก้ไข (วิดเจ็ตแต่ละชนิดมีตัวอย่างสด ตัวเลือกของตัวเอง ปุ่มย้าย < > และปุ่มลบ)
  - วงกลมสีแดงคือลบ (เลิกทำได้)
  - "+ เพิ่มวิดเจ็ต" / "+ เพิ่มแอป" ใช้เติมช่องที่ว่าง
  - กด เสร็จสิ้น (หรือ Esc) เมื่อแก้ไขเสร็จ

วิดเจ็ต
-------
นาฬิกาเข็ม      เข็มวินาที ตัวเลข วันที่ - เปิด/ปิดได้ทีละอย่าง
นาฬิกาดิจิทัล    วินาที คำทักทาย วันที่ - เปิด/ปิดได้ทีละอย่าง ขนาดปกติหรือใหญ่
ปฏิทิน          แสดงเลขสัปดาห์ (ISO) ได้ (วันเริ่มต้นสัปดาห์ตั้งได้ในการตั้งค่า)
นาฬิกาโลก       ชื่อเมือง และเขตเวลาใดก็ได้ของ Windows (พิมพ์ค้นหาได้ เช่น "tokyo" หรือ "UTC+9")
                แบบดิจิทัลหรือแบบเข็ม พร้อมวินาที แสดง "วันนี้/พรุ่งนี้" และเวลาที่ต่างกัน
โน้ต            หัวข้อ ข้อความ (Enter = ขึ้นบรรทัดใหม่, Ctrl+Enter = บันทึก) ขนาดตัวอักษร และสี
รูปภาพ          รูปเดียว หรือทั้งโฟลเดอร์แบบสไลด์โชว์ (เปลี่ยนภาพแบบค่อย ๆ จางทุก 10 วินาที / 30 วินาที /
                1 นาที / 5 นาที สุ่มลำดับได้) กรอบแนวนอน สี่เหลี่ยมจัตุรัส หรือแนวตั้ง แบบเต็มกรอบ (ครอปภาพ)
                หรือแบบพอดีกรอบ (เห็นทั้งภาพ) และใส่คำอธิบายภาพได้ ภาพจากโทรศัพท์จะหมุนให้ตั้งตรงเอง
                โฟลเดอร์จะถูกอ่านใหม่ทุก 5 นาที รูปที่คัดลอกเข้าไปจึงขึ้นเองโดยอัตโนมัติ
ถ้าเลือกวิดเจ็ตมากกว่าที่จอจะวางเรียงได้ แถววิดเจ็ตจะย่อขนาดลงให้พอดี

แอปในแถบแอป
------------
Zoom             เปิดแอป Zoom ถ้าไม่มีแอป จะเปิด zoom.us/join ใน Microsoft Edge แทน
Microsoft Teams  เปิด Teams ตัวใหม่ (หรือ Teams ฟรี / Teams แบบคลาสสิก) ถ้าไม่มี จะเปิด Teams บนเว็บ
Google Meet      เปิด https://meet.google.com ใน Microsoft Edge
Webex            เปิดแอป Webex ถ้าไม่มี จะเปิด web.webex.com
เพิ่มได้อีก        Microsoft Edge, Google Chrome, ตัวสำรวจไฟล์ (This PC สำหรับแฟลชไดรฟ์ USB),
                 แคสต์หน้าจอ (Win+K), โหมดการแสดงผล (Win+P), PowerPoint, เว็บไซต์ใดก็ได้ และ
                 โปรแกรม / ทางลัด / เอกสารใดก็ได้ แอปจาก Store: shell:AppsFolder\<AppUserModelId>
แต่ละแอปเลือกไอคอนในตัวได้ 32 แบบและสี 12 สี หรือเลือก "แอป" เพื่อใช้ไอคอนของโปรแกรมเอง

การตั้งค่า
---------
ภาษา (อัตโนมัติ / English / ไทย) ชื่อห้อง คำบรรยาย นาฬิกา 12/24 ชั่วโมง วันเริ่มสัปดาห์ เปิดพร้อม Windows
เปิดหน้าจอค้างไว้ นาฬิกาพักหน้าจอ (หรี่เป็นนาฬิกาที่ค่อย ๆ เลื่อนตำแหน่งเมื่อไม่มีการใช้งาน 5/15/30 นาที
ช่วยป้องกันจอทีวีเกิดภาพค้าง) PIN ผู้ดูแล รูปลักษณ์ (อัตโนมัติ / มืด / สว่าง) สีเน้น ภาพพื้นหลังโหมดมืดและ
โหมดสว่าง (ไฟล์ JPG/PNG ใดก็ได้ ถ้าเว้นว่างจะใช้ภาพออโรราในตัว) แก้ไขหน้าจอหลัก และออกจากโปรแกรม

PIN ผู้ดูแล (ไม่บังคับ): เมื่อตั้งไว้ การเปลี่ยนชื่อห้อง การตั้งค่า และการแก้ไขแถบแอปจะต้องใส่ PIN ก่อน
ปลดล็อกแล้วใช้ได้ 5 นาที ปุ่ม Alt+F4 จะไม่ปิด RoomHome ให้ใช้ การตั้งค่า > ออกจากโปรแกรม

รายการ Wi-Fi ขึ้นว่า "Windows ซ่อนรายการเครือข่ายไว้"?
  Windows 11 (24H2 ขึ้นไป) ให้แอปแสดงรายการ Wi-Fi ได้เฉพาะเมื่อเปิดการเข้าถึงตำแหน่งเท่านั้น:
  การตั้งค่า > ความเป็นส่วนตัวและความปลอดภัย > ตำแหน่ง > "อนุญาตให้แอปเดสก์ท็อปเข้าถึงตำแหน่งของคุณ"
  ในหน้าต่าง Wi-Fi มีปุ่มไปยังหน้านั้นและไปยังรายการ Wi-Fi ของ Windows ให้แล้ว เครือข่ายองค์กร
  (802.1X) ต้องเชื่อมต่อผ่านรายการ Wi-Fi ของ Windows

ไฟล์การตั้งค่า
-------------
%APPDATA%\RoomHome\config.json (แยกตามผู้ใช้ Windows บันทึกทุกครั้งที่มีการเปลี่ยนแปลง)
ถ้าต้องการตั้งค่าล่วงหน้าให้หลายห้อง ให้แก้ไข RoomHome.defaults.sample.json แล้วบันทึกไว้ข้าง
RoomHome.exe ในชื่อ RoomHome.defaults.json ไฟล์นี้จะใช้กับผู้ใช้ทุกคนที่ยังไม่มีการตั้งค่า
คีย์เพิ่มเติม: "language" ("auto", "en", "th"), "dockSlots" (3-8), "volumeStep" (1-20 %),
"monitor" (0 = จอหลัก, 1..n = จอที่ระบุ)

การติดตั้ง
---------
RoomHome-1.2.0-setup.exe จะเลือกเวอร์ชันที่เหมาะกับพีซีให้เอง และถามภาษา (English หรือ ไทย)
ซึ่ง RoomHome จะใช้ภาษานั้นจนกว่าจะเปลี่ยนที่ การตั้งค่า > ภาษา ตัวเลือกระหว่างติดตั้ง: เปิดพร้อม Windows
(สำหรับผู้ใช้ทุกคน) และทางลัดบนเดสก์ท็อป ติดตั้งแบบเงียบ (ใช้ภาษาที่แสดงของ Windows ถ้าไม่ได้ระบุ /LANG):
    RoomHome-1.2.0-setup.exe /S [/LANG=en|th] [/NOAUTOSTART] [/DESKTOP] [/ARCH=x64|x86|arm64] [/D=C:\Folder]
ถอนการติดตั้งได้ที่ การตั้งค่า > แอป หรือ "C:\Program Files\RoomHome\Uninstall.exe" /S
ไฟล์แบบพกพา RoomHome-1.2.0-<arch>.exe ใช้งานได้เลยโดยไม่ต้องติดตั้ง

บรรทัดคำสั่ง
-----------
RoomHome.exe --quit            ปิด RoomHome ที่เปิดอยู่ (บันทึกการตั้งค่าก่อนปิด)
RoomHome.exe --config <file>   ใช้ไฟล์การตั้งค่าอื่น
RoomHome.exe --lang en|th      เริ่มด้วยภาษานี้ (เหมือนเลือกที่ การตั้งค่า > ภาษา)
RoomHome.exe --dry-run         แสดงว่าจะเปิดแอปหรือปิดเครื่องอะไร โดยไม่ทำจริง
RoomHome.exe --window 1280x720 เปิดในหน้าต่างแทนการเต็มจอ (สำหรับทดสอบ)
RoomHome.exe --diag <file>     เขียนรายงาน: แอปที่พบ เสียง Wi-Fi LAN และอินเทอร์เน็ต

เคล็ดลับสำหรับเครื่องแบบคีออสก์
---------------------------
- สำหรับพีซีประจำห้อง ให้ใช้ เปิดพร้อม Windows ร่วมกับการลงชื่อเข้าใช้อัตโนมัติของบัญชีภายใน
  เช่นบัญชีชื่อ "Meeting Room"
- เปิด "เปิดหน้าจอค้างไว้" ถ้าไม่ต้องการให้ทีวีเข้าสู่โหมดสลีปเลย หรือปิดไว้แล้วให้แผนการใช้พลังงาน
  ของ Windows ปิดจอเองตอนกลางคืน
- ปิดเครื่อง / รีสตาร์ท ทำงานเหมือนเมนู Start แอปที่ค้างอยู่จะถูกปิด
